# Mise v0.0.4

Weekly meal planner demonstrating a deeply AI-integrated Vaadin application. This release adds in-flight chat control and forward planning, moves onto Spring AI 2.0.0 GA, and introduces a release gate that verifies the user manual against the live model.

## What's new (high level)

- **"Stop" a running AI turn, with busy feedback** (UC-013) — the chat shows when Mise is working and you can type `stop` to cancel an in-flight turn; whatever was already written is kept and marked _(stopped)_.
- **Generate future weeks by chat** (UC-011) — "plan next week" / "plan June" generates forward weeks (forward-only, idempotent, capped), so Reports has runway to trend over.
- **Spring AI 2.0.0 GA** — upgraded from the milestone build, in lockstep with Vaadin's AI components; plus dependency bumps (Spring Boot, Vaadin rc1, DramaFinder, CI actions).
- **Manual-verify release gate** — a new opt-in test layer that drives the user manual's "Example queries" against the **live** model (headless + real browser), so the manual can't claim a capability that doesn't actually work.
- **Reliability hardening** — raised the LLM client timeout so slow Reports reshapes don't abort mid-stream (#90), steered reporting SQL to H2 date functions (#85), fixed viewed-week chat grounding on the AI tool thread (#79), and de-flaked the AIIT suite with per-test + per-fork timeouts.
- **Docs & tooling** — expanded user manual (model download links, context/VRAM notes, slow/hard-query markers, cover graphic, "Built with Vaadin" attribution) and a new `/pre-release` readiness-check skill.

## Tests run for this release

Verified on `dev-main`, layers run serially, against the live primary model (**Qwen 35B**, `Qwen3.6-35B-A3B-UD-Q4_K_XL`).

| Layer | Command | Tests | Result |
|---|---|---:|---|
| Unit + Browserless | `./mvnw test` | 193 | ✅ pass |
| Playwright IT (real browser) | `./mvnw -Pit verify` | 74 | ✅ pass |
| AI tool IT (live LLM) | `./mvnw -Pai-it verify` | 30 | ✅ pass¹ |
| Manual-example gate (live LLM, headless + browser) | `./mvnw -Pmanual-verify verify` | 17 | ✅ pass |
| **Total** | | **314** | **all green on the 35B** |

¹ One intermittent assertion (`GenerateFutureWeeksAIIT.eightWeekCap_notExceeded`) — the 8-week cap is enforced per tool-call rather than per-turn, so a model that batches calls can occasionally exceed it. Passed 3/3 on isolated re-run; tracked as a non-blocking robustness item (#105).

**Nice-to-know — smaller model (Qwen 4B, `Qwen3.5-4B-UD-Q8_K_XL`):** 15/17 on the manual gate. The 4B degrades only on the hardest tasks — "plan next week" landed a week late, and the most complex chart reshape ("vegetarian dinners by month") exceeded the 5-minute timeout. Both are documented 4B limitations; the 35B is the recommended default.
